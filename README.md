# 🌿 Moringa Habana

Sitio web informativo y catálogo de productos de moringa para el emprendimiento "Moringa Habana".

## 📋 Descripción

Moringa Habana es una página web diseñada para promocionar productos derivados de la moringa, educar sobre sus beneficios y facilitar el contacto con los clientes. El sitio funciona como catálogo informativo + venta física en sede.

## 🎯 Objetivo

- Presentar los productos de moringa (polvo, cápsulas, semillas, té, aceite, alimentos, cosméticos)
- Educar sobre los beneficios y usos de cada producto
- Mostrar la ubicación física con mapa interactivo
- Facilitar el contacto a través de redes sociales

## 🛠️ Tecnologías Utilizadas

- **HTML5** - Estructura
- **CSS3** - Estilos y diseño responsive
- **JavaScript (Vanilla)** - Interactividad y lógica
- **Leaflet.js** - Mapas interactivos
- **Google Fonts** - Tipografía

## 🚀 Páginas

| Página       | Descripción                                        |
| ------------ | -------------------------------------------------- |
| **Inicio**   | Hero, beneficios en acordeón, productos destacados |
| **Catálogo** | Todos los productos con filtros y búsqueda         |
| **Detalle**  | Información completa de cada producto              |
| **Contacto** | Redes sociales + mapa interactivo                  |

## 💰 Precios

Todos los precios están en **CUP (Pesos Cubanos)**.

## 📱 Responsive

El sitio está diseñado con enfoque **mobile-first**, adaptándose a todos los tamaños de pantalla.
